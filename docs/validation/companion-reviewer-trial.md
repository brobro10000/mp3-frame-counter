# Companion reviewer qualification trial

This disposable documentation-only pull request exercises an owner-authorized automated review under the repository's
existing required checks and approval rules. The dedicated reviewer must inspect the exact change and current evidence
before deciding whether approval is justified. A submitted approval must name the reviewed commit and be read back from
GitHub to establish whether it counts toward the effective approval requirement.

The trial is closed without merging after its result is recorded. It does not change application requirements,
acceptance expectations, CI, permissions, branch protections, release behavior or deployment status. An automated
machine-user review is labeled as automated and must not be presented as an independent human review.

Traceability: APP-V1-011 and the repository-control review process in docs/repository-controls.md. This record exercises
the review boundary only; it is not evidence of completing an application phase or publishing a release.

Any subsequent content change requires a fresh review of its new commit before approval can qualify.
